# GitHub upload scope

This repository snapshot preserves the MQSim/SWANS source variants, experiment
configuration, completed results, run records, analysis scripts, spreadsheets,
and Obsidian research notes created through 2026-08-29.

The following local data is intentionally not uploaded:

- `Trace/`: original MSRC trace corpus (about 30 GB)
- `XML_result/**/work/`: temporary converted traces and incomplete run scratch data
- `tmp/`: temporary build/test data
- `**/node_modules/`: local dependency junctions

These files remain on the local machine and were not deleted. Completed result
XML files and the epoch-Mu CSV data are included.
